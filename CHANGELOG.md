# Changelog

- Momo in a side pane (band above the prompt on narrow terminals) and the status line

- Warnings for risky commands on macOS, Linux and Windows
- End-of-turn verdicts, `/momo changes`, `/momo recap`, `/momo pet`, `/momo quiet`
